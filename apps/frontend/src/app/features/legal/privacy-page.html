Politique de confidentialité

1. Introduction

Bienvenue sur Bar à Dés (« barades.com »). Nous nous engageons à protéger votre vie privée et vos données personnelles. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos informations.

2. Données collectées

Nous collectons les types de données suivants :

  • Données d'inscription : nom d'utilisateur, adresse email, mot de passe (chiffré)
  • Données de profil : prénom, nom (optionnels), avatar
  • Données d'utilisation : sessions créées, réservations, participations aux groupes
  • Données techniques : adresse IP, type de navigateur, données de géolocalisation (avec votre consentement)

3. Utilisation des données

Vos données sont utilisées pour :

  • Créer et gérer votre compte utilisateur
  • Permettre la création et la participation aux sessions de jeu
  • Faciliter la communication entre membres
  • Envoyer des notifications relatives à vos activités
  • Améliorer nos services et l'expérience utilisateur
  • Assurer la sécurité de la plateforme

4. Partage des données

Nous ne vendons jamais vos données personnelles. Vos informations peuvent être partagées avec :

  • Autres utilisateurs : votre nom d'utilisateur et les informations de profil publiques sont visibles par les autres membres
  • Prestataires techniques : hébergement (Vercel, Render), base de données (Supabase), emails transactionnels (Resend)
  • Autorités légales : si requis par la loi

5. Sécurité des données

Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos données :

  • Chiffrement des mots de passe (bcrypt)
  • Connexions sécurisées (HTTPS)
  • Authentification par tokens JWT
  • Accès restreint aux données sensibles

6. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : consulter vos données personnelles
  • Droit de rectification : corriger vos informations
  • Droit à l'effacement : supprimer votre compte et vos données
  • Droit à la portabilité : exporter vos données
  • Droit d'opposition : vous opposer à certains traitements

Pour exercer ces droits, contactez-nous à privacy@barades.com.

7. Conservation des données

Vos données sont conservées tant que votre compte est actif. En cas de suppression de compte, vos données personnelles sont effacées sous 30 jours, à l'exception des données nécessaires pour des obligations légales.

8. Contact

Pour toute question concernant cette politique de confidentialité, contactez-nous :

  • Email : privacy@barades.com
